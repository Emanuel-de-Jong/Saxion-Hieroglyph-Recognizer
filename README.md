# Hieroglyph Recognizer
For the class: 3.1 BDT ML

Trains AI models on hieroglyph images so they can recognize new images in the future. Multiple old fashioned SL classification algorithms are trained on characteristics extracted from the images and the model with the best test results is used. There is also a simple web interface for drawing your own hieroglyph and having the model classify it.

These are the same hieroglyphs used in the [Recommendation AI And Custom CNN](https://github.com/Emanuel-de-Jong/Saxion-Recommendation-AI-And-Custom-CNN)
